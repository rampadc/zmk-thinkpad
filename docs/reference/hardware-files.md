# Hardware files

## T430 Revision A

Revision A is the only manufactured custom controller documented here. Its
schematic is available on GitHub:

- [View the Revision A schematic](https://github.com/rampadc/zmk-thinkpad/blob/main/docs/engineering/architecture/hardware/t430/revision-a/schematic.pdf)
- [Download the Revision A schematic](https://raw.githubusercontent.com/rampadc/zmk-thinkpad/main/docs/engineering/architecture/hardware/t430/revision-a/schematic.pdf)

Revision B files describe work in progress. They are not released hardware.
